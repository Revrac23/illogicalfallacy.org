Post Hoc

Assuming that because one event happened after another, the first event caused the second.

Category: Causal Reasoning
Also known as: Post Hoc Ergo Propter Hoc
Type: Informal fallacy

Definition

Post hoc reasoning assumes that because one event occurred after another, the earlier event caused the later event.

Example

“I wore my lucky shirt and then our team won. The shirt caused us to win.”

The sequence of events does not establish a causal relationship.

Why It’s Fallacious

Events can occur in sequence for many reasons. Establishing causation requires more than simply showing that one event happened before another.

How to Recognize It

Ask:

“What evidence shows that the first event caused the second?”

If the only evidence is that one event happened first, the argument is likely committing a post hoc fallacy.
