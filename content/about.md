Illogical Fallacy is a practical reference for recognizing common errors in reasoning. The examples show how arguments work in everyday settings and what evidence would make them stronger.

## Corrections

If you spot an error, an unclear example, or a broken citation, [open an issue on GitHub](https://github.com/Revrac23/illogicalfallacy.org/issues). Include the article URL, the passage in question, and a suggested correction. If you have a source, include a link and point to the section that supports the change.
